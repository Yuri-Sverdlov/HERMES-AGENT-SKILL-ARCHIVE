# 5 Golden Rules for Group Scenes

1. **Один орган = один контакт**  
   Рот может делать либо минет, либо кунни, либо издавать звуки — но не всё одновременно.

2. **Стоны = рот свободен**  
   Если персонаж громко стонет — его рот сейчас не занят активным сексуальным действием.

3. **Направления контакта должны быть явными**  
   «Входит во влагалище», «языком по вульве», «членом в рот» — без двусмысленности.

4. **Физиология и биомеханика первичны**  
   Можно ли физически находиться в этой позиции и одновременно выполнять описанные действия?

5. **Каждый контакт = чёткая связка**  
   Позиция + конкретный орган + партнёр + тип контакта.
