# author.today — конкретика (проверено)

## URL-схемы

| Что | Адрес |
|---|---|
| Страница произведения (оглавление, флаги доступа) | `https://author.today/work/<workId>` |
| Читалка, первая глава / одностраничное произведение | `https://author.today/reader/<workId>` |
| Читалка, конкретная глава | `https://author.today/reader/<workId>/<chapterId>` |

Оглавление на странице произведения — ссылки вида `/reader/<workId>/<chapterId>`
с названием главы внутри `<a>` (парсить
`re.findall(r'<a[^>]+href="/reader/<workId>/(\d+)"[^>]*>(.*?)</a>', html, re.S)`,
из второго поля снять теги). Пустой список = одна глава — брать `/reader/<workId>`.

## Признаки доступа (в HTML страницы произведения, экранированы как `&quot;`)

| Поле | Значение → что значит |
|---|---|
| `"allowDownloads":true` + `downloadText:"Скачивать могут только зарегистрированные пользователи"` | официальная загрузка после бесплатной регистрации |
| `"allowDownloads":false` + `downloadText:"Возможность скачать появится после подписки на автора или его соавтора(-ов)"` | читать свободно, скачать — только по платной подписке на автора |
| `"isPurchased":false` и цена в карточке | платное: читалка пишет «Книга находится в платном доступе», «оплатите доступ», «Продажа книги приостановлена» |
| HTTP 403 на страницу произведения анонимно | доступ «Для друзей»: нужен статус друга автора |

Кнопка «Скачать» анонимному посетителю вызывает `app.showLoginModal()` — то есть
упирается во вход, а не в отсутствие функции.

## Извлечение текста

- Контейнер: `#reader` (внутри `<section id="reader" …>`, приложение на Knockout.js).
- Текст главы НЕ лежит в исходном HTML — только в отрендеренном DOM; плейн-HTTP
  отдаёт пустую оболочку.
- Хвост текста — строки «← Название» и «Название →» (ссылки на соседние главы): срезать обе.
- Шапка: `Оглавление`, `Вернуться на сайт`, `Настройки` (у одностраничных первым
  идёт `Описание`), затем название главы, затем текст.
- Возрастной гейт: кнопка с текстом ровно `Да, мне есть 18`; после клика текст
  открывается без входа в аккаунт.
- Неразрывные пробелы `\xa0` встречаются массово — нормализовать в обычный пробел.

## Оценка полноты

Размер произведения печатается в карточке («Размер: 63 893 зн., 1,60 а.л.») и в
списке от Юрия. Собранный файл выходит на 1–3 % больше (шапка, названия глав,
разделители) — это норма; недобор в разы = пропущенная глава.

## Известные ограничения

- Таблицы и графики в статьях опубликованы картинками (`/content/YYYY/MM/DD/<hash>.jpg`) —
  `innerText` их не отдаёт; в файле остаются только подписи («Таблица 1»),
  сами данные теряются (встречалось в статьях про сложность текста и об изданиях).
- Для многоглавых произведений читалка всегда открывает одну главу; ссылка
  «Читать» на карточке ведёт на ту же читалку.
